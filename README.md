# 星隙几何

基于 `F:/F-P/game` 原版消灭星星3D制作的故事版，位于 `F:/F-P/gamess`。原项目保持不变。

## 运行

直接打开 [index.html](index.html)，无需安装依赖或构建。浏览器限制本地脚本时，在此目录运行静态服务器再打开。

## 已接入的流程

- 开始页使用已提供的动态星空飞船背景；点击黄色“开始游戏”后进入同背景的模式选择页，两个黄色按钮分别进入冒险模式和挑战模式。
- 遇袭改为五格原图漫画：撞击、损坏、驾驶舱、迫降、裂谷，再接原有救援剧情。图片位于 `assets/story/opening/`。漫画以星空为背景，使用暖纸边框与对白气泡，每页四格，桌面2×2、手机纵向阅读，支持前后翻页与刷新续读。

- 萤灯谷（普通）、风轮镇（旋转）、映光庭（视角），每章5关，尺寸5×5至9×9。
- 暂时开放全部15个冒险关卡、11个挑战关卡、三个章节和全部故事，不要求通关或读完剧情才能进入。未通关按钮为实体灰色，仍可点击；通关后在按钮内部下方显示“已通关”。
- 每关从0分开始。萤灯谷目标为700/1300/2100/3000/4200；风轮镇800/1450/2300/3300/4600；映光庭1000/1750/2700/3850/5200。一至五星门槛按关卡单独配置，结算奖励计入本关分数。依据见[关卡分数配置](docs/关卡分数配置.md)。
- 达标且收尾完成后记录本关成绩并返回地图；跳关不伪造前面关卡的通关状态，故事可自行选择阅读。“下一站”直接切换到后续场景。
- 故事相册采用双页笔记本，每次展示4段漫画预览，右下角箭头翻页；点击打开完整故事，返回时保留原页码。
- 全员送行后选择离开或留下；分别播放回家线或留下线的0号漫画，再进入对应挑战故事。“假设他留下来的生活”可从回家线选关页开启IF线，保留原离开结局；有未读故事时先读完再切换。
- 挑战模式（原创造模式）11关全部开放，无分数目标，保留任务失败条件，每关配生活故事。
- 新版独立存档，不读取或覆盖旧版记录。刷新后点击继续旅程可恢复待读故事；存档不可用时有提示。
- 三地游戏背景分别为青绿、暖金、蓝紫；3D方块使用柔和六色、奶油色印记、细描边与分层光照，HUD及弹窗改为浅色。

## 海艺美术交接

### 已接入的留下线漫画

用户提供的 `游戏/5 - 副本/0.png` 至 `11.png` 已按原图复制到 `assets/story/comics/stay-0.png` 至 `stay-11.png`。
0 号用于“留下”结局及“假设他留下来的生活”入口；1–11 号依次对应挑战模式第 1–11 关的生活故事。
故事相册共用这些整页漫画，标题与 B0–B11 剧本一致，保留图片内对白并沿用桌面/手机等比例显示。原有故事 ID、关卡玩法及存档格式保持兼容。

### 已接入的离开回家线漫画

用户提供的 `游戏/home - 副本/0.png` 至 `11.png` 已原样复制到 `assets/story/comics/home-0.png` 至 `home-11.png`。
点击“离开”播放0号《把灯带回家》，读完进入“回家后的日子”。挑战第1–11关对应1–11号漫画，标题采用A1–A11剧本。
回家线使用独立的 `home-01` 至 `home-11` 故事ID；留下/IF线继续使用 `life-01` 至 `life-11`。两线相册记录分别保留，共用挑战关卡成绩。已在一条线通关的关卡，切换另一条线后重玩仍可收录该线的新故事。

当前是分镜预览版：角色是姓名标记，地图用配色布局，漫画格显示画面说明。这些不是完成的插画。正式人物、环境、漫画图片由你用海艺AI生成。

1. [海艺AI素材制作指南](docs/海艺AI-素材制作指南.md)：8个人物、2张飞船、3张地图场景、3张游戏背景，共16张基础素材。每张附完整提示词、比例、文件名。
2. [海艺AI逐镜提示词](docs/海艺AI-逐镜提示词.md)：146格完整提示词与对应对白。
3. [完整剧情分镜](docs/完整剧情分镜.md)：全部故事脚本。

先定小航和萤火号，再定其他角色与场景，最后画漫画。每格单独生成，不在图片中生成文字；网页显示中文对白。沿用角色参考图保持一致。PNG放到 `assets/story/` 指定位置，刷新即可显示。路径清单为 `assets/story/manifest.json`。

```powershell
node scripts/check-story-assets.cjs
```

加 `--list` 显示缺图文件。`node scripts/export-story.cjs` 从剧情数据重新导出提示词与清单。

## 主要文件

| 文件 | 作用 |
| --- | --- |
| js/journey-state.js | 存档、门槛、目标分、结局、待播队列 |
| js/journey-data.js | 原创人物、场地、全部分镜 |
| js/journey.js | 地图、漫画、相册、结局与引擎接入 |
| journey.css | 故事界面与手机布局 |
| game-theme.css | 游戏背景、浅色HUD与弹窗 |
| js/scene.js | WebGL卡通材质、拾取和相机 |
| 其他原版js文件 | 棋盘、重力、机关、挑战、音效 |

## 验证

```powershell
node --test
node scripts/verify-journey-updates.cjs
```

第二条需要 Windows Microsoft Edge，启动独立隐藏浏览器；报告和截图在 `.qa/journey-updates/`。脚本检查全部关卡入口、跳关存档、模式选择、灰色按钮、笔记本翻页及桌面/手机布局。部分结算状态直接设置，另有真实可见方块点击检查，不代表自动手动打通全部关卡。旧的 `verify-journey.cjs` / `verify-challenge.cjs` 面向历史流程。

## 当前限制

- 正式插画尚未生成，人物行走当前为标记移动；飞行以分镜脚本及图片平移动效承载，正式观感依赖后续素材。
- 分数以6000局基础棋盘采样校准，机关附加门槛为设计估计，仍需真人难度测试。
- 存档属于当前浏览器/来源，清除数据或切换访问地址不会自动迁移。
