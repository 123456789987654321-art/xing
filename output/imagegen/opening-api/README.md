# 开场图片 API 试画

最新确认：小航驾驶萤火号在宇宙飞行，被陨石击中；漫画表现慌张和飞船起火；随后以2D动画飞向一颗星球，坠入地表的巨大裂谷。裂谷不是宇宙空间裂缝。

本批只试画图片，不修改游戏开场流程。01、02、05是无边框2D动画关键画面；03、04是漫画单格。它们是视觉试稿，正式动画还需要背景、飞船、陨石和特效的独立图层。

文件：prompts.jsonl，使用 imagegen 官方技能 CLI 的 generate-batch。默认模型 gpt-image-2，1536×1024，中等质量，每个提示词一张。先生成01检查飞船定稿，再以它为参考制作其余画面更有利于一致性；独立批量生成不保证人物和飞船完全一致。
