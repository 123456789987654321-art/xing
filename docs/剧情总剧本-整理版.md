# 萤火号：剧情总剧本（整理版）

本文按已确认的故事整理，用于核对剧情、制作漫画和后续接入游戏。不是生图提示词，也不代表程序已经实现这些新剧情。与旧稿冲突时，以本稿所记录的最新设定为准。

## 一、故事主旨

送货员小航驾驶萤火号穿行宇宙，意外遭遇陨石，坠入一颗星球表面的巨大裂谷。飞船损坏，小航落到裂谷最底层。他得到当地居民的帮助，修复飞船，逐步向上，认识新的朋友，也参与解决不同地区的困难。

当通往外界的道路终于打开，他有两种选择：回到自己的生活，或在裂谷正式安家。两种选择都有温暖而完整的后续，没有哪一种是错误结局。

整体气氛友善、明亮。冲突来自故障、误会、胆怯和生活中的小麻烦，不以邪恶势力或持续灾难推动故事。

## 二、地点与人物

### 地点

| 地点 | 位置与玩法 | 视觉与故事作用 |

## 三、游戏与剧情的触发顺序

1. 新游戏播放开场：2D宇宙动画 → 船内事故漫画 → 2D坠入裂谷动画。
2. 首次进入每个地区，播放该章入场漫画，不占五个关卡的名额。
3. 每章五关，棋盘依次为5×5、6×6、7×7、8×8、9×9。
4. 每关分数从0开始，达到该关目标并完成成功结算才算通关；失败可重试。
5. 通关后回到地区选关地图，解锁下一个按钮，小航沿路线前进，再播放本关剧情。首次只有第一章第一关亮起。
6. 第一、二章第五关剧情结束后，乘飞船前往下一地区，播放下一章入场漫画。
7. 第三章第五关播放送别漫画；小航尚未登船离开，随后出现去留选择。
8. 选择后播放对应IF开场，解锁挑战模式。每通过一个挑战关卡，播放当前分支的一段漫画。
9. 十一个挑战关卡全部通关后，自动解锁另一分支的开场与全部漫画，供回看。原选择保留，不需要重新打十一关。

“创造模式”沿用既有挑战玩法，在本文统一写作“挑战模式”。每关目标分的具体数值属于游戏配置，不在剧本中虚构。

## 四、开场：意外坠落

| 镜头 | 表现形式 | 内容 |
| --- | --- | --- |
| O1 宇宙航行 | 2D动画 | 固定全景。小飞船在画面中央飞行，体积很小但轮廓可辨，宇宙背景缓慢移动。 |
| O2 陨石撞击 | 2D动画 | 陨石进入画面击中飞船，短暂闪光和震动；飞船偏离航线。 |
| O3 舱内惊慌 | 一页多格漫画 | 警示灯亮起；小航抓住操纵杆；船外受损部位冒烟起火；小航努力控制方向。用动作表达慌张，不把文字画进图片。 |
| O4 坠入裂谷 | 2D动画 | 星球表面的巨大裂谷全景，镜头全程固定。受损飞船从远处进入，拖着烟迹落入裂谷；不跟拍、不推近，不是宇宙传送门。 |

开场受损飞船必须明显破损；后续修复、升级都有过程，不能在入场时自动变成完好飞船。

## 五、第一章：萤灯谷——先把飞船修好

阻碍：飞船无法正常飞行。阿芽负责组织修理，小航通过五关逐渐融入当地生活。

### C1-0 入场｜掉下来的新朋友

触发：开场坠落后。

分镜顺序：受损飞船停在谷底，小航爬出舱门 → 阿芽、团团发现他并确认平安 → 阿芽检查飞船，小航得知暂时无法离开 → 两位新朋友带他去工坊。

结果：从陌生与不安，进入有人愿意帮助他的环境。

### C1-1 第一关｜修船的第一步

分镜顺序：阿芽拆开受损处检查 → 小航帮忙整理可以使用的零件 → 两人确认仍缺少修理材料 → 团团借来提灯，三人开始合作。

结果：修理目标明确，小航不再只是被帮助的人。

### C1-2 第二关｜一起走过小桥

分镜顺序：小航与团团外出寻找材料 → 来到需要修整的小桥 → 小航修好松动桥板，陪团团走过 → 两人带着材料回到工坊。

结果：材料带回，团团对小航更加信任。后续桥应保持完好，不能反复坏掉。

### C1-3 第三关｜拿走零件的灰翎

分镜顺序：修理时发现关键翅片不见了 → 找到拿着翅片的灰翎 → 小航发现他正在修自己的小装置 → 双方因零件用途产生分歧，修船暂时停下。

结果：出现小冲突，但不把灰翎塑造成恶意反派，也不改变金黄小鸟的定稿造型。

### C1-4 第四关｜多留了一张椅子

分镜顺序：灰翎带回翅片 → 大家让他参与修理，各自做力所能及的事 → 灰翎完成一项小工作 → 晚饭时大家为他多留一张椅子。

结果：归还零件解决实际问题，一起吃饭完成关系变化。

### C1-5 第五关｜萤火号再次起飞

分镜顺序：飞船修复完成 → 小航短距离试飞成功 → 阿芽说明目前只能先飞到上层风轮镇 → 朋友把熟悉的灯与祝福交给小航 → 小航独自驾驶飞船离开，大家留在谷中挥手。

结果：能飞，但还不能直接离开裂谷。下一站风轮镇。

## 六、第二章：风轮镇——让风重新向上

阻碍：向上的风道失效，现有飞船也需要升力升级。铜伯解决机械问题，风铃引路与联络，灰翎学习在行动前与人沟通。

### C2-0 入场｜风带来的信

分镜顺序：萤火号抵达风轮镇 → 风铃迎接小航，交来谷底朋友的信 → 风铃带他认识铜伯 → 铜伯检查飞船，指出停止工作的向上风道，以及需要增加的升力装置。

结果：认识新伙伴，明确“修风道、再升级”的目标。

### C2-1 第一关｜停下来的风轮

分镜顺序：三人沿装置查找故障 → 铜伯发现松动支架与偏移传动带 → 小航帮忙整理拆下的部件 → 众人标记需要维修的位置。

结果：找到故障；本关不直接恢复整条风道。

### C2-2 第二关｜重新转起来

分镜顺序：先锁定停止的机构 → 修复支架、调整传动带 → 移开工具进行低速测试 → 机械恢复转动，但气流仍偏向侧面。

结果：机械能运转了，向上的通路还未打开。

### C2-3 第三关｜帮忙之前，先问一问

分镜顺序：灰翎想帮忙，独自调整导风板 → 气流偏转，大家发现角度不对 → 灰翎停下，承认是自己改动 → 铜伯展开示意图，邀请他一起重新调整。

结果：问题是好心办错事，不重复第一章偷拿零件。此页末尾仍处在讨论方案阶段。

### C2-4 第四关｜向上的风

分镜顺序：依据示意图确认正确位置 → 小航与灰翎分别操作，铜伯校准 → 导风板明显改变倾角并锁紧 → 侧向气流变成稳定向上的气流。

结果：风道恢复。这页必须看见“调整前后”的差别；同一个木框导风机构不能突然变成巨大风车。

### C2-5 第五关｜带着风出发

分镜顺序：铜伯为萤火号安装腹部升力环 → 完成低空悬浮测试 → 灰翎交给小航修补包 → 风铃指出映光庭方向 → 小航沿向上气流独自飞走，朋友挥手告别。

结果：飞船成为后续统一使用的升级版。只有一个黄铜实体升力环，青蓝灯窗嵌入其中；不带脚架。

## 七、第三章：映光庭——出口之外，生活在哪里

阻碍：出口附近气流危险，导航光路失效。阿镜校准光路，晴哨确认航路，露婆婆照看灯塔。

### C3-0 入场｜看得见的天空

分镜顺序：飞船抵达白石平台 → 晴哨接引，阿镜与露婆婆迎接 → 小航看见通往外界的天然出口 → 众人指向熄灭或偏移的导航设施，示意此时不能起飞离开。

结果：希望就在眼前，但需要先把安全航路标出来。

### C3-1 第一关｜偏离的光

分镜顺序：阿镜带小航沿光路检查 → 用小型测试光确认反射方向 → 找到第一处角度偏差 → 晴哨记录位置，准备校准。

结果：找到问题，主灯尚未恢复。

### C3-2 第二关｜接上第一束光

分镜顺序：小航帮助转动棱镜 → 阿镜确认光束进入目标点 → 众人跟随光束查看下一处设施 → 发现支架缺件，后段光路仍断开。

结果：完成一段光路，明确下一个具体障碍。

### C3-3 第三关｜没说出口的担心

分镜顺序：灰翎听到小航即将离开的消息，变得沉默 → 小航留意到他，停下倾听 → 灰翎表达害怕朋友离开后的失落 → 他仍选择帮忙，找到掉落的支架零件并带回。

结果：灰翎没有故意破坏航路，也没有藏起零件。他学会表达不舍，同时支持朋友。

### C3-4 第四关｜灯塔重新亮起

分镜顺序：装回支架 → 阿镜校准后续光路 → 露婆婆启动灯塔 → 晴哨检查导航光与风向，确认可通行路线。

结果：安全路径得到指引，不是魔法消除了整个裂谷的气流。

### C3-5 第五关｜大家都来了

本页建议五格，最后一格留较大空间。所有朋友是来送别，不是一起登船。

1. 顶部横格：小航、阿镜和晴哨确认出口航路已恢复。阿镜拿地图，晴哨拿旗，不能换成风铃。
2. 中部一格：阿芽和团团带来补给，小航迎接他们。
3. 中部一格：铜伯、风铃、灰翎到来；风铃保留长水滴头，灰翎保持原始独立定稿。各自简单姿势、彼此留空。
4. 中部一格：小航拿着熟悉的小灯，回想一路受到的帮助。此格主角只能是小航。
5. 底部长格：小航站在朋友和飞船之间，尚未登船。阿芽、团团、铜伯、风铃、灰翎、阿镜、露婆婆、晴哨共八位朋友留在平台，分散站立。飞船保持升级版，不加脚架。

漫画结束后显示选择：

- **回到自己的生活**：小航独自离开，回到家乡星港小镇。
- **留在这里生活**：小航正式在裂谷安家，用飞船作为移动小家。

若选择离开，离开动画后保留没有飞船的出口画面，显示“假设他留下来的生活”入口。该入口用于说明或进入另一种生活的IF体验；完整另一线漫画按十一关全通规则自动开放。实际按钮与挑战进度的关联接入时须保持一致，不提前显示未解锁漫画。

## 八、IF回家线A：回到自己的生活

回家不是开启新冒险，也不是带所有朋友搬走。小航独自生活，恢复驾驶飞船运送信件和货物的工作。家乡采用温暖朴素的星港小镇；没有“家人在家等他”的情节。

| --- | --- | --- |

| A11 挑战第11关 | 下次见，写在信里 | 和朋友分享生活与点心 → 收藏纪念卡 → 小航独自登船离开 → 回到家乡灯下写新信。探望结束，联系继续。 |

## 九、IF留下线B：我的家会飞

小航正式成为裂谷居民，不是暂住。飞船保留原外形，只把后舱布置为紧凑生活空间，在萤灯谷、风轮镇、映光庭之间送信、运货和生活。

| 编号与触发 | 标题 | 漫画叙事顺序与落点 |
| --- | --- | --- |
| B0 选择留下 | 这次，我想留下 | 小航放下出发行李 → 向朋友表达决定 → 清理后舱储物空间 → 挂上熟悉的小灯。正式开始安家。 |

## 十、漫画与素材制作规则

- 每段剧情默认一页多格，最多两页。漫画采用大小格搭配，阅读顺序从左到右、从上到下。
- 漫画图片不写对白、标题、拟声词、按钮或页码。需要的文字由游戏界面另行显示。
- 游戏内用居中非全屏弹窗显示，周围仍可看见压暗的地图；图片本身不画弹窗外景。
- 如果确有第二页，由程序在第一页右侧中间放翻页箭头，不让生图模型绘制箭头。
- 主线三个入场加十五个通关剧情，共18段；两个IF开场加22个挑战剧情，共24段。合计42段，另有开场动画与事故漫画。段数不等于最终图片文件数。
- 生图参考按角色逐张列出，不能把角色合成一个参考图。以角色定稿和正确飞船为准，错误漫画页不能用于锁定外形。
- 每格只画该格需要的人物。送别群像中小航与八位朋友身份明确，不能同一格出现两个风铃、让风铃登船替代小航，或遗漏绿色阿芽。
- 修理动作分开完成，避免多人同时握同一道具；人物之间保留背景空隙，减少穿模与多手。

## 十二、连续性核对

1. 开场飞船坠入的是星球裂谷，主角从下往上走；不是一开始飞船已停在顶层。
2. 第一章完成修复，第二章完成升级，第三章打开安全航路，三章解决的问题不同。
3. 升级后的飞船始终同一外形，单个实体黄铜升力环，无脚架。
4. 灰翎的变化是从不善表达、拿走零件，到归还、合作，再到支持朋友离开，最后独立经营小修理台。
5. 主线最后是送别与选择；小航独自回家，朋友不集体登船。
6. 回家线结束于探望后返回自己的生活；留下线结束于正式融入裂谷，二者不能串线。
7. 提灯、小屋、生活舱等属于剧情设计，并不自动意味着存在可上传的图片素材。
