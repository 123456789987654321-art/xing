# Firefly Journey Implementation Plan

> Execute inline using executing-plans; user approved implementation, no further design approval needed.

**Goal:** Deliver playable story progression plus complete SeaArt production prompts, with artwork supplied later by user.
**Architecture:** Original engine copied intact. Pure persistent campaign state, narrative data, and a DOM adapter wrap existing normal/challenge lifecycle.
**Tech Stack:** Native JavaScript, CSS, HTML, WebGL; Node built-in tests and Edge CDP.
**Spec:** ../specs/2026-10-20-firefly-design.md

## Global Constraints
- 3 chapters × 5 levels, sizes 5–9 each; independent score; sequential unlock.
- 11 creative levels, unlocked only by stay/IF; original challenge rules.
- Original files preserved; no external image API; missing art is explicitly a storyboard.
- Chinese copy, keyboard/mobile/reduced-motion, no build or dependencies.

## Review Focus
- Reload during comic or after victory preserves pending stories and never skips progression.
- Replay and repeated settlement cannot award double progression.
- Locked levels cannot start through direct adapter methods.
- Failure, retry and early exit never unlock the next level.
- Endings stay distinct; leave alone never unlocks creative, IF does.
