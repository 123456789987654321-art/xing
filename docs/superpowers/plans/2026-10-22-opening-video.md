# 开场视频接入计划

需求：使用用户指定目录内的遇袭MP4，黄色动漫登入按钮启动，电脑与手机全屏视口适配，结束后衔接已有剧情。

1. 将视频复制到 assets/story/video，使用项目相对路径，原文件不变。
2. 独立视频播放器负责用户手势播放、结束/跳过只触发一次、失败后重试、离开页面后停止。
3. 首页保留待机画面，点击登入后播放视频；不改动存档和关卡解锁。播放完成才继续现有故事或存档。
4. 播放器覆盖视口，视频 contain 保留完整画面；支持移动端内联播放、安全区和全屏能力降级。
5. 先做播放器行为测试，再接入入口与样式，运行已有旅程测试及新测试。确认媒体复制一致。

重点验证：重复点击、播放被拒绝、资源失败、跳过与结束同时发生、页面退出后的迟到事件、横竖屏不裁画面。
