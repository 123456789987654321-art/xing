# 海艺 AI · 星隙几何素材制作指南

本文件的提示词可直接复制使用。不依赖海艺的某个模型或特定版本界面。分辨率是构图建议，具体以所选模型支持的尺寸为准。

## 先做哪几张

先做 **8位角色头像 + 2张飞船设定 + 3张场景，共13张核心图**。先定小航和萤火号，再定其他角色，最后做场景。全部定稿后才开始单格漫画，避免每张图长相不同。角色三视图是可选辅助资产。

1. 每位角色先选定一张满意的定稿。后面出现同一角色时使用该定稿作为角色参考（如果所用模型/工作流支持参考图）。固定角色外形描述，记录使用的模型和参数；只固定随机种子不能保证跨场景一致。
2. 风格参考使用你发的彩色漫画图，只参考线稿、网点与上色，不照搬其中人物的服装或身份。
3. 漫画**一格一张图**，不要让模型生成整页多格排版。对白、分镜编号和按钮由游戏绘制，图片里不要生成文字。
4. 建议角色头像1:1（如1024×1024），场景和漫画16:9（如1536×864）。不要拉伸；必要时等比裁切。角色脸部放在画面中央偏上，漫画主要人物和关键动作放在中央60%区域，兼容手机裁切。
5. 图片按下方文件名保存为真正的PNG文件，放入项目的 assets/story 对应目录。不要只把JPG的扩展名改成PNG。刷新网页即会显示已有图片；缺图位置继续显示分镜说明。
6. 不需要透明背景，头像在网页中裁成圆形；飞船设定用干净浅色底。正式漫画场景要有环境背景。
7. 多人画面尽量先保证主要两三个人一致。大合照先做构图，再逐个检查角色脸、衣服和人数；必要时分区域修正，不能仅依赖一次生成。

## 统一风格词

下面每条具体提示词已包含风格词，直接复制对应完整提示词即可。

> 原创日系彩色漫画，纯2D手绘，清晰细腻的深色线稿，赛璐璐上色，少量柔和水彩环境纹理，适量漫画网点，人物表情生动，友善阳光的奇幻冒险世界，暖金色日光，青绿与奶油白为主色，低饱和背景与清楚的人物配色，精致自然的构图，全年龄，角色衣服完整，无文字、无对白气泡、无边框、无水印。

## 通用反向提示词

所用工作流支持反向提示词时填入；不支持时把关键限制附在正向提示词末尾。

> 3D，三维渲染，写实照片，真人，塑料皮肤，黏土，恐怖，血腥，阴森，过度性感，裸露，成人内容，文字，汉字，英文字母，对白气泡，字幕，标志，水印，拼图，多格漫画，多视角混在同一画面，多余手指，多余肢体，扭曲手脚，重复人物，模糊，低清，过曝，杂乱背景。

## 分镜生成与验收

逐格完整提示词见 [海艺AI-逐镜提示词.md](海艺AI-逐镜提示词.md)。角色ID/文件名与本文件一致。先做 opening-01 至 opening-06，确认主角和飞船一致后再批量做后续。

验收：人物没有换脸或换衣；场景所在高度正确；飞船损坏/修复状态正确；人数与分镜一致；对白不用出现在图片里；手机居中裁切后仍能看懂主要动作；leave-06 必须是没有飞船和人物的空出口。

## 交给游戏的方法

将PNG放到指定目录，刷新 index.html。想改变文件格式或路径时，同时修改 js/journey-data.js 的 asset 字段。不要在导出的提示词文档里改路径代替代码修改。运行 node scripts/export-story.cjs 会从剧情数据重新生成本指南和分镜清单。
